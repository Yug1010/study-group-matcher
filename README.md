# Campus Study Group Matcher

A dynamic web application built for cloud computing and DevOps practices, allowing students to create and track study group sessions.

## Features
- Server-rendered dynamic home page displaying active study groups.
- Form submission with input validation to add new groups.
- JSON API endpoint (`/api/groups`) and health check route (`/health`).
- Dynamic footer showing the active commit ID.

## Local Development
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm test` to execute automated tests.
4. Run `npm start` to start the app locally on port 3000.
